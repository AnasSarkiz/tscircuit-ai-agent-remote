# THEN ROUTE THE COMPLETE PCB

Once the above checks pass, enable routing and route the board.

This must be treated as a serious production-oriented routing pass.

Do NOT simply run an autorouter and declare success.

---

# 4-LAYER STACK

Use the intended 4-layer architecture.

Preferred intent:

```text
L1 — components + critical/short signals
L2 — continuous GND plane
L3 — power distribution + slower signals
L4 — additional signals
```

Keep L2 as continuous a ground reference as reasonably possible.

Do not unnecessarily cut or fragment the ground plane.

Avoid routing signal traces across large ground-plane gaps.

---

# TRACE WIDTH RULES

Do not use one default trace width for everything.

Define net classes or equivalent routing rules.

## Low-current digital signals

Typical GPIO / SPI / control:

approximately:

`0.15–0.20 mm`

Use larger widths where routing space allows.

## Power rails

Calculate required widths from actual current.

At minimum separately review:

- VBUS 5 V
- PACK_BAT
- VSYS
- 3V3
- display backlight power
- speaker amplifier power
- haptic motor current

Do not use thin signal traces for power.

For high-current battery/system paths, prefer:

- wide traces
- polygons/pours where appropriate
- multiple vias when changing layers

Design for expected peak current, not merely average current.

The provisional system load is around the 1.5 A range and battery capability is higher, so PACK_BAT and VSYS must be treated as meaningful power nets.

Calculate the actual minimum copper width required for:

- continuous current
- peak current
- acceptable temperature rise
- 1 oz copper unless another copper weight is selected

Document the calculation.

---

# USB ROUTING

USB D+ and D− require special treatment.

Route them as a matched differential pair.

Check:

- same reference plane
- minimal stubs
- minimal vias
- short route
- continuous ground beneath them
- spacing consistency
- no routing through noisy power section

Aim for appropriate USB 2.0 differential impedance.

Do not claim exact 90 Ω differential impedance unless the actual JLCPCB stackup, dielectric thickness and trace geometry have been calculated.

If impedance control is required, calculate:

- trace width
- pair spacing
- copper thickness
- dielectric thickness
- dielectric constant

using the actual board stackup.

Keep USB ESD protection close to the connector.

---

Absolutely no:

Inspect every PCB layer.

# SWITCHING REGULATOR ROUTING

The TPS63802 section needs careful layout.

Follow TI's recommended layout as closely as possible.

Minimize:

- switching loop area
- L1/L2 switch-node area
- distance to input capacitor
- distance to output capacitor

Keep the switch node away from:

- microphones
- microphone clock/data
- antenna
- sensitive ADC
- USB

Use wide short power connections.

Ground return must be low impedance.

Review the actual copper against the manufacturer layout recommendations after routing.

---

# CHARGER ROUTING

For BQ24074:

Keep:

- input capacitor close
- BAT capacitor close
- OUT capacitor close
- exposed pad properly grounded
- high-current BAT/OUT/VBUS paths short and wide

Check thermal copper.

The charger may dissipate significant heat while charging.

Do not bury it in an isolated tiny copper island.

---

# MICROPHONE ROUTING

Two microphones are sensitive audio components.

Keep them away from:

- regulator switch node
- USB
- speaker amplifier output
- haptic motor current
- high-current power traces

Keep microphone clock/data routes controlled and reasonably short.

Provide clean ground reference.

Review possible crosstalk and return paths.

Remember:

**B-005 microphone solder-paste issue is still a fabrication blocker unless it has now been resolved upstream.**

Routing success does NOT resolve B-005.

---

# SPEAKER ROUTING

MAX98357 output is differential.

Never connect either speaker output to GND.

Route speaker + and − as a pair.

Keep them:

- reasonably close together
- away from microphones
- away from antenna
- away from sensitive logic where practical

Review amplifier supply current path separately.

---

# HAPTIC ROUTING

Route motor current separately from sensitive microphone/audio circuits.

Ensure the haptic MOSFET:

- has correct gate resistor/pulldown
- has appropriate protection
- has suitable current path
- does not inject large return currents through sensitive ground paths
