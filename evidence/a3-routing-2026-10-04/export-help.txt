Usage: tsci export [options] <file>

Export tscircuit code to various formats

Arguments:
  file                              Path to the package file

Options:
  --x-ray-net <name-or-id>          Inspect a PCB net by exact name, display
                                    name, or connected element ID (repeatable)
                                    (default: [])
  --hidden-layer-opacity <opacity>  Other copper opacity during X-Ray, from 0 to
                                    1 (default: 0.2)
  -f, --format <format>             Output format (json, circuit-json,
                                    schematic-svg, schematic-pdf, pcb-svg,
                                    pcb-png, gerbers, readable-netlist, gltf,
                                    glb, specctra-dsn, kicad_sch, kicad_pcb,
                                    kicad_zip, altium, kicad-library, srj, step,
                                    assembly-svg, component-box-3mf)
  -o, --output <path>               Output file path
  --layer <layer>                   PCB front layer: top or bottom
  --disable-parts-engine            Disable the parts engine
  --show-courtyards                 Show courtyard outlines in PCB SVG output
  -h, --help                        display help for command
